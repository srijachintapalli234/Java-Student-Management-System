# Java Student Management System

A console-based Student Management System built using Java, JDBC, and MySQL.

## Features

- Add Student
- View All Students
- Search Student
- Update Student
- Delete Student
- MySQL database connectivity

## Technologies Used

- Java
- JDBC
- MySQL
- MySQL Connector/J
